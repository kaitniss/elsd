# Интерактивная карта проекта ремонта квартиры Ирины

Самодостаточный интерактивный сайт и рабочие материалы карты зависимостей проекта Elena Beach Apartments, Limassol.

## Открыть сайт

Откройте [`index.html`](./index.html) локально в браузере. Файл не требует сборки, сервера или внешних библиотек.

## Содержимое

- `index.html` — интерактивная WBS-карта, критический путь, роли и вопросы Алексею;
- `data/dependency-register.csv` — реестр для Google Sheets и будущего таск-менеджера;
- `data/dependency-register.json` — машинный источник данных;
- `docs/RENOVATION_WBS_MERMAID.md` — Mermaid mind map и критический путь;
- `docs/DEPENDENCY_TABLE.md` — полная таблица зависимостей;
- `docs/GOOGLE_DRIVE_TASK_MANAGER.md` — схема синхронизации Drive и системы задач;
- `docs/CANVA_CLIENT_FRAGMENT.md` и `assets/CANVA_CLIENT_FRAGMENT.svg` — облегчённый клиентский фрагмент.

## Граница достоверности

Критический путь пока логический, а не календарный. Сроки и длительности не назначены. Предварительные планы и 3D не заменяют натурный обмер. Красный статус означает «не подтверждать до осмотра, замера, вскрытия, расчёта или испытания».
