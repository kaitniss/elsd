# Квартира Ирины

Статический сайт проекта. Публикуется содержимое `dist/`.

Планы, 3D-модель GLB, самостоятельные HTML-просмотры, презентация, фотографии и документы находятся в `dist/assets/`. Изображения из сохранённой презентации сопровождаются авторскими подписями. Внешние сервисы для просмотра материалов не требуются.

Для локального просмотра: `python3 -m http.server 8000 --directory dist`, затем открыть localhost:8000.

Планировка и модели предварительные. Сохранённый экспорт плана не подменяет обзорную 3D-реконструкцию; расхождения и допущения перечислены в приложенных документах.

Палитра сохраняется только в браузере пользователя; её можно скачать отдельно.
